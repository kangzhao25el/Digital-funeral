# A Digital Funeral of a Girl
A Digital Funeral of a Girl is an interactive web project exploring digital identity, memory and disappearance. It was created as an individual project for the Digital Image module at King’s College London.
The work invites viewers to experience the gradual dismantling, transformation and disappearance of a girl’s digital image. As the narrative unfolds, images are progressively replaced by metadata, ending with a flatline. It asks: when a person is reduced to data that can be stored and retrieved, what do we actually preserve of her?
I independently developed the concept, narrative structure, visual design and interactions. I used a large language model to assist with HTML, CSS and JavaScript code generation, debugging and iteration, bringing the idea to life as a single-page interactive website.

《一个女孩的数字葬礼》是一个以数字身份、记忆与消逝为主题的交互式网页作品，也是我在伦敦国王学院 Digital Image 课程中完成的个人项目。
作品让观众逐步经历一个女孩的数字形象被拆解、转化与消隐的过程。随着叙事推进，图像逐渐被元数据取代，最终以一条平直的生命线收尾，邀请观众思考：当一个人被转化为可存储、可读取的数据，我们究竟保留了她的什么？
我独立完成概念构思、叙事结构、视觉与交互设计，并使用大语言模型辅助 HTML、CSS 和 JavaScript 的代码生成、调试与迭代，将创意实现为可在浏览器中体验的单页网页。
